# Reference

## Public API

| item | what it is |
|---|---|
| transform definitions | the rules themselves — data, reviewed as data |
| `desugar` pass | the named pass the rewrite engine runs before eval |

## Crate

| crate | role |
|---|---|
| `desugar` | transform-pass source — pure handl |

## Build and test

```bash
cargo build     # sibling [patch] tables resolve deps from ../<repo>
cargo test      # cargo test (embedding) + the plugin's transform tests
```

Dependencies are git deps on `branch = "main"`; locally the `[patch]` tables
point at sibling checkouts (regenerated by `host/scripts/dev-link.sh`).
